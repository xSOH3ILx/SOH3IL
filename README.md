## قابلیت‌های کلیدی

### ۱. حل اساسی مشکل جابجایی یادآورهای ماهانه شمسی (The Zero-Drift Solar Engine)
بسیاری از تقویم‌های اندرویدی به دلیل تبدیل تاریخ به میلادی یا فواصل ۳۰ روزه، یادآورهای ماهانه را در ماه‌های ۳۱ یا ۲۹ روزه جابجا می‌کنند (مثلاً یادآور روز ۳ ماه بعد از چند ماه روی ۲ یا ۴ ماه زنگ می‌زند). در **سُهیل**:
- قوانین یادآور مستقیماً بر مبنای تقویم جلالی (`RecurrenceRule`) در پایگاه داده ذخیره می‌شوند.
- موتور زمان‌بندی در هر چرخه، دقیقاً تاریخ روز هدف را در ماه بعد خورشیدی محاسبه کرده و به میلی‌ثانیه یونیکس تبدیل می‌کند.
- برای روز ۳۱ام در ماه‌های ۶ ماه دوم (که ۳۰ روزه‌اند) و اسفند، سیاست هوشمند انطباق با آخرین روز ماه (`SNAP_TO_LAST_DAY`) اعمال می‌شود.

### ۲. پیش‌یادآورهای چندگانه (Pre-Reminders)
- امکان تنظیم اعلان‌های پیش از موعد (مثلاً ۱۵ دقیقه قبل، ۳۰ دقیقه قبل، ۱ ساعت قبل یا ۱ روز قبل).

### ۳. اعلان‌های تعاملی و بیداری از Doze Mode
- استفاده از `AlarmManager.setAlarmClock()` جهت بیدار کردن CPU در زمان خاموش بودن صفحه.
- دکمه‌های کنترلی مستقیم روی نوتیفیکیشن: **«انجام شد»** و **«تعویق ۱۵ دقیقه (Snooze)»**.
- `BootReceiver` اختصاصی برای زمان‌بندی مجدد و بلادرنگ کلیه آلارم‌ها پس از ریستارت یا آپدیت گوشی.

### ۴. طراحی یکپارچه با الهام از FarsiUI و Google Material 3
- راست‌چین ذاتی (RTL-first) با چیدمان استاندارد فارسی.
- تایپوگرافی کامل با اعداد فارسی (۱۲۳).
- تم‌های متنوع: روشن (Light)، تاریک (Dark)، مشکی عمیق (AMOLED Black)، و هماهنگ با رنگ پس‌زمینه گوشی (Dynamic Monet Color در اندروید ۱۲ به بالا).

### ۵. معماری ماژولار و کم‌حجم (Modular Clean Architecture)
پروژه به صورت تفکیک‌شده به ماژول‌های مستقل تقسیم شده است:
- `core:jalali`: موتور محاسبات نجومی جلالی به زبان کاتلین خالص و بدون وابستگی اندروید (با سرعت تست فوق‌العاده بالا).
- `core:model`: مدل‌های دامنه‌ای و قوانین تکرار.
- `core:database`: پایگاه‌داده محلی SQLite/Room با انتیتی‌های یادآور و مناسبت‌ها.
- `core:scheduler`: زمان‌بند AlarmManager، کنترل مجوزها و رسیورهای بوت و آلارم.
- `core:designsystem`: کامپوننت‌های FarsiUI، پالت رنگ و تم Material 3.
- `core:updater`: سیستم بررسی نسخه با GitHub Releases و نصب مستقیم فایل APK درون برنامه.
- `feature:calendar`: صفحه تقویم، شبکه روزها و جزئیات روز.
- `feature:reminder`: فرم باتم‌شیت ثبت و ویرایش یادآورها و قوانین تکرار.
- `feature:settings`: مدیریت تم و بررسی بروزرسانی.
- `app`: نقطه ورود، مجوزها و بیلد امن با امضای دیجیتال.

### ۶. امضای رسمی و بروزرسانی درون‌برنامه‌ای (In-App Update)
- دارای فایل Keystore اختصاصی از روز اول برای امضای نسخه‌های Release.
- ماژول `core:updater` به صورت خودکار آخرین نسخه منتشرشده در گیتهاب را بررسی کرده و امکان دانلود و نصب مستقیم APK را برای کاربر فراهم می‌کند.

### ۷. توسعه مبتنی بر تست (TDD)
تمامی فرمول‌های محاسباتی، سال‌های کبیسه، روزهای ۲۹/۳۰/۳۱ ماه، و فواصل تکرار ماهانه توسط تست‌های Unit پوشش داده شده‌اند:
```bash
./gradlew testDebugUnitTest
```

## فرآیند بیلد و استقرار با GitHub Actions

پروژه به صورت خودکار با هر Push به شاخه `main` یا تگ‌های نگارش (`v*`) در GitHub Actions تست شده و فایل‌های APK خروجی (Debug و Signed Release) تولید می‌شوند.

```
git tag v1.0.1
git push origin v1.0.1
```
